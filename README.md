Este é meu primeiro projeto que enviei para o Github.


# Como enviar projetos para o Github
- Precisa ter o **GIT** instalado e o **Gitthub Desktop**
- Abrir o **CMD** na pasta sdo projeto e executar o comando:`git init`
- Fazer o**commit** no Github Desktop e depois clivcar e depois clicar em `push` parav enviar 
   - Se é a primeira vez , precisa clicar em `publish`
   - Lembrar de, preferencialmente, deixar o projeto como **public**


   ## Como baixar projetos 
   Abrir o **CMD** e digitar o `Git clone(Link do repositório)`
